# Pruebas

No hay pruebas implementadas. Cuando se autorice iniciar la aplicación, ubicar pruebas junto a cada módulo backend/frontend o en suites organizadas por componente. La selección de herramientas y comandos queda por definir con el stack aprobado; no se asume Vitest/Supertest de la propuesta Node anterior.

Cobertura prevista: reglas del catálogo y variantes, permisos por rol, mapeos por canal, transiciones de pedidos, resultados simulados de publicación y adaptación de errores. Los conectores reales requieren pruebas con ambientes y credenciales expresamente autorizados.
